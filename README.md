
A simple Users Directory web application built with HTML, CSS, and JavaScript. This project demonstrates how to fetch data from an external API, process JSON responses, and dynamically display user information on a webpage.

## About the Project

This project was created as part of my JavaScript learning roadmap (Day 13 — JSON & APIs).

The application retrieves user information from the JSONPlaceholder API and displays each user in an organized card layout.

## Features

- Fetches user data from an external API.
- Processes API responses using JSON.
- Displays users dynamically on the webpage.
- Shows each user's:
  - Full name
  - Email address
  - City
  - Phone number
- Uses CSS Grid for responsive card layouts.
- Includes basic API error handling.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
- Fetch API
- JSON
- DOM Manipulation

## API Used

[JSONPlaceholder](https://jsonplaceholder.typicode.com/users)

The application retrieves sample user data from the JSONPlaceholder `/users` endpoint.

## Concepts Practised

- API Architecture

- GET Requests
- Promises and `.then()`
- `response.json()`
- `JSON.stringify()` and `JSON.parse()`
- `forEach()`
- `document.querySelector()`

## How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. Ensure you have an active internet connection so the application can retrieve data from the API.
